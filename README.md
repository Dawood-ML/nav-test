# Daylist

A small, local-first to-do app built with vanilla JavaScript and Node.js. Add, complete, filter, remove and clear tasks. Tasks are stored in your browser on the device you use; they are not synced or backed up.

## Run locally

Requires Node.js 18 or newer. No third-party packages are required.

```sh
npm start
```

Open <http://127.0.0.1:3000>. To use another port, run `PORT=4000 npm start`.

## Test

```sh
npm test
```
